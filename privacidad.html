Privacidad

Qué datos se tratan en esta web. Respuesta corta: ninguno tuyo.

Responsable

El responsable de este sitio es Daniel Castaños Mefle. Sus datos de contacto están en danimefle.com/aviso-legal.

Formularios

Los formularios de esta web son de demostración. Al pulsar el botón de enviar, se comprueba que los campos estén rellenos, se vacían y aparece un aviso. No se envía nada a ningún servidor, no se guarda en el navegador y nadie recibe lo que escribas. Los campos no tienen nombre de envío y, sin JavaScript, el botón de enviar está desactivado.

El formulario de cita pregunta por la zona que te molesta, que es un dato de salud. Como no se envía ni se guarda, tampoco se trata: se queda en tu pantalla hasta que se vacía.

Analítica

Para saber cuántas visitas tiene la web se usa Plausible Analytics, instalado en un servidor del titular (analytics.danimefle.com), que es por tanto el responsable de este tratamiento. No usa cookies. Para contar visitantes únicos calcula cada día un identificador a partir de la dirección IP y del navegador, mezclado con una clave que se borra a las 24 horas; la IP no se guarda. Lo que queda son datos agregados: páginas vistas, web de procedencia, país, navegador y tipo de dispositivo.

Alojamiento

La web se sirve desde Cloudflare Pages. Como cualquier servidor web, el proveedor puede tratar datos técnicos de la conexión, como la dirección IP, para entregar las páginas y protegerlas de ataques. Puedes consultar la política de privacidad de Cloudflare en su web.

Tus derechos

Como esta web no guarda datos tuyos, no hay nada que consultar, corregir o borrar. Si tienes cualquier duda, puedes escribir al titular por los medios que figuran en danimefle.com/aviso-legal.
